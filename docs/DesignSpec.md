# DesignSpec · Solo CLI 控制台

> 主题：任务指挥中心（Mission Control）。面向单人高频操作，信息密度高但层次分明，浅色底、白卡片轻阴影、单一强调色、状态色系统清晰。
> 2026-09-15 由深色切换为浅色（用户反馈深色看不清）。

## 1. 调色板

| Token | 值 | 用途 |
|---|---|---|
| `--bg-0` | `#F4F6FA` | 页面底色 |
| `--bg-1` | `#FFFFFF` | 侧栏、顶栏 |
| `--bg-2` | `#FFFFFF` | 卡片（阴影 `0 1px 2px rgba(15,23,42,.04), 0 4px 16px rgba(15,23,42,.05)`） |
| `--bg-3` | `#F1F4F9` | 卡片内嵌区块 |
| `--line` | `rgba(15,23,42,0.08)` | 分割线、卡片边 |
| `--fg-0` | `#0F172A` | 主文字 |
| `--fg-1` | `#475569` | 次要文字 |
| `--fg-2` | `#94A3B8` | 占位、禁用 |
| `--accent` | `#4F6BED` | 强调、主按钮、活动导航、链接 |
| `--accent-soft` | `rgba(79,107,237,0.15)` | 强调底色 |
| `--ok` | `#059669` | 完成、上传成功、连通 |
| `--run` | `#D97706` | 运行中、分析中、排队 |
| `--warn` | `#EA580C` | 标黄核验、超时 |
| `--err` | `#E11D48` | 失败、中断、标红 |
| `--info` | `#0284C7` | 已上传、信息提示 |

状态 → 色：`AVAILABLE` fg-1 · `QUEUED/RUNNING/ANALYZING` run · `FINISHED/REVIEWED` ok · `UPLOADED` info · `FAILED/INTERRUPTED` err · `TIMEOUT` warn · `DONE` fg-2。

## 2. 字体

- 界面：`Inter, "PingFang SC", "Noto Sans SC", system-ui` — 标题 600、正文 400
- 等宽（题号、SessionID、命令、事件流）：`"JetBrains Mono", "SF Mono", Menlo, monospace`
- 字号：页标题 22/28 · 卡片标题 15/22 · 正文 13/20 · 辅助 12/16 · 数字大屏 32/36（tabular-nums）

## 3. 布局

- 左侧固定侧栏 224px（品牌 + 五个导航：总览 / 题库 / 运行舱 / 题目 / 设置），底部显示三项连通状态小圆点
- 顶栏 56px：面包屑 + 槽位占用 `2 / 3` + 全局操作
- 内容区最大宽 1440，内边距 24，卡片间距 16，卡片圆角 12，内嵌区块圆角 8
- 断点：≥1280 双列/三列网格；1024–1279 双列；<1024 单列

## 4. 组件

| 组件 | 规范 |
|---|---|
| 题卡 TaskCard | 左上等宽题号徽标；右上难度胶囊（困难=warn 描边）；标题行 = 任务类型 · 语言；正文两行截断；底部按钮「领取并启动」（accent 实心） |
| 舱位卡 RunCard | 顶部状态条 3px（按状态色）；标题 = 题号 + 阶段文字；三列指标：耗时 / 轮次 / tokens；下方最近 3 条工具调用（等宽，淡入）；hover 显示「查看事件流」「停止」 |
| 事件流 Timeline | 左侧时间轴，节点按事件类型着色（assistant=accent，tool_use=run，tool_result=fg-1，result=ok/err）；工具调用可折叠显示参数与结果摘要 |
| 五维编辑器 ScoreEditor | 每维一行：维度名 · 1–5 分段选择器 · 描述 textarea（等宽）· 证据链 chips（点击跳事件流对应步骤）· 核验标记（ok/warn/err 圆点 + 悬浮原因） |
| 核验条 VerifyBar | 通过 / 标黄 / 标红 三段计数；存在标红时「上传」按钮禁用并给出原因 |
| 连通状态 Probe | 圆点 + 名称 + 上次检测时间；点击触发重测，检测中脉冲动画 |
| 设置表单 | 分组卡片：solo-qa 身份 / CC 网关 / Cursor / 路径与调度；密钥输入框掩码 + 「显示」切换 + 「测试连接」 |

反馈状态：所有异步操作有 loading（骨架屏或按钮 spinner）、空态插画文字（不放插图，用等宽提示行）、错误 toast 含可读原因与重试。

## 5. 动效

- 页面切换 120ms 淡入；卡片 hover 上浮 2px + 边线变 accent-soft
- 运行中状态条呼吸（1.6s）；新事件插入 160ms 滑入
- 禁止大面积渐变与光效，保持工程感

## 6. 禁用项

- 不使用表情符号作为状态指示
- 不使用纯 HTML 表格样式；所有列表用 Naive UI DataTable 深色主题或自定义卡片
- 不出现未对齐的数字列（一律 `tabular-nums` 右对齐）
